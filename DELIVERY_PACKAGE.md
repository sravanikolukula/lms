## 🚀 QUICK START (5 MINUTES)

### Do This Now:

**1. Install Package**
```bash
npm install @google/generative-ai
```

**2. Get API Key**
- Go to: https://ai.google.dev/
- Click "Get API Key"
- Copy your key

**3. Configure**
Edit `.env.local`:
```
GEMINI_API_KEY=AIzaSy...your_key_here...
```

**4. Restart Server**
```bash
npm run dev
```

**5. Test It**

- Refresh page
